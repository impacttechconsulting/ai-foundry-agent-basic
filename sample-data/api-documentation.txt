# TechForward API Documentation

## Overview
The TechForward API provides programmatic access to platform features, data, and services. This RESTful API uses standard HTTP methods and returns JSON responses.

## Authentication
All API requests require authentication via API key. Include your API key in the request header:

```
Authorization: Bearer YOUR_API_KEY
```

API keys can be generated in the developer portal under Account Settings.

## Rate Limits
- Standard accounts: 1,000 requests per hour
- Premium accounts: 10,000 requests per hour
- Enterprise accounts: 100,000 requests per hour

Rate limit information is included in response headers:
- X-RateLimit-Limit: Request limit per hour
- X-RateLimit-Remaining: Remaining requests
- X-RateLimit-Reset: Time when limit resets

## Endpoints

### User Management
#### GET /api/users
Retrieve a list of users with optional filtering.

Parameters:
- limit (integer, optional): Number of users to return (default: 20, max: 100)
- offset (integer, optional): Number of users to skip for pagination
- search (string, optional): Search term to filter users by name or email

Response:
```
{
  "users": [
    {
      "id": "user_12345",
      "name": "John Smith",
      "email": "john.smith@company.com",
      "created_at": "2024-01-15T09:30:00Z",
      "last_login": "2024-10-15T14:22:00Z",
      "status": "active"
    }
  ],
  "total": 150,
  "page": 1,
  "per_page": 20
}
```

#### POST /api/users
Create a new user.

Request body:
```
{
  "name": "Jane Doe",
  "email": "jane.doe@example.com",
  "department": "Engineering",
  "role": "developer"
}
```

#### GET /api/users/{id}
Retrieve details for a specific user.

### Data Analytics
#### GET /api/analytics/metrics
Retrieve analytics metrics for the specified time period.

Query parameters:
- start_date (string, required): Start date in YYYY-MM-DD format
- end_date (string, required): End date in YYYY-MM-DD format
- metric_type (string, optional): Type of metric (default: "all")
- granularity (string, optional): Time grouping ("daily", "weekly", "monthly")

### File Management
#### POST /api/files/upload
Upload files to user storage.

Use multipart/form-data to upload files. Maximum file size is 50MB.

#### GET /api/files/list
List files for the authenticated user.

Query parameters:
- type (string, optional): Filter by file type (e.g., "document", "image", "spreadsheet")
- limit (integer, optional): Number of files to return (default: 20, max: 100)

## Error Handling
API responses use standard HTTP status codes:
- 200: Success
- 201: Resource created
- 400: Bad request
- 401: Unauthorized
- 403: Forbidden
- 404: Resource not found
- 429: Rate limit exceeded
- 500: Server error

Error response format:
```
{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "The request contains invalid parameters",
    "details": [
      {
        "field": "email",
        "issue": "Invalid email format"
      }
    ]
  }
}
```
